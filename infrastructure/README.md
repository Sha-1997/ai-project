# JovianeX Platform: Infrastructure & Deployment Configs

This directory hosts configurations, environment variables guides, Docker containers settings, and deployment blueprints for running and hosting the JovianeX AI platform:

* **Local Containers:** configurations for local PostgreSQL and Redis DB services (`docker-compose.yml` wrappers).
* **Environments:** `.env` keys tracking and variables checks.
* **Orchestration:** Kubernetes Helm blueprints, reverse proxies (Nginx), and security certificates.

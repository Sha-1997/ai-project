# Contributing Guidelines - JovianeX AI platform

Thank you for contributing to the **JovianeX AI platform**.

---

## 1. Branch Naming Rules
* Features: `feature/your-feature-name`
* Bug fixes: `fix/target-bug-description`
* SRE Hotfixes: `hotfix/critical-remediation`

---

## 2. Coding Standards
* Run Prettier check before committing changes:
  ```bash
  npm run format
  ```
* Enforce semantic commit prefixes matching `feat:`, `fix:`, `docs:`, or `chore:`.
* Write unit and integration tests covering functional components.
